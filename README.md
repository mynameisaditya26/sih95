# SIH 2026 Inspection Platform

Complete project for Smart India Hackathon 2026 Problem Statement #95.

## Features
- Role-based access (Admin, Inspector, Institution)
- Random surprise inspections with GPS verification
- Evidence upload with geo-tagging
- AI-powered image analysis (mock with abstraction)
- Risk and compliance scoring
- AI-generated reports
- Real-time notifications and dashboard updates
- CCTV/demo monitoring
- Violation management and corrective actions
- Audit logs
- Interactive maps and charts

## Tech Stack
- Backend: Node.js, Express, MongoDB, Socket.IO
- Frontend: React, Leaflet, Recharts
- AI Service: Python, FastAPI (mock/real)
- Docker: Docker Compose
